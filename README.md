# Corplife Saúde — downloads de teste

Versões de **teste** do aplicativo Corplife Saúde para Android.
Todos os dados dentro do aplicativo são **fictícios**.

## Baixar

**[Baixar a versão mais recente (APK)](https://github.com/fabio8181/corplife-saude-downloads/releases/latest/download/Corplife-Saude.apk)**

Não precisa de conta no GitHub.

## Como instalar no Android

1. Abra o link acima no celular e baixe o arquivo.
2. Toque no arquivo baixado (em *Meus Arquivos → Downloads*).
3. Se o celular avisar que não permite instalar apps desta fonte, toque em **Configurações** e ligue **Permitir desta fonte**.
4. Toque em **Instalar** e depois em **Abrir**.
5. Se aparecer o aviso do Play Protect, toque em **Mais detalhes → Instalar mesmo assim**.

## Como entrar

Na tela de login, **segure o dedo na logo por 3 segundos** e escolha um perfil de teste (a Maria tem todos os serviços).
